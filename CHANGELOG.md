# Changelog

All notable changes to HoloForge are documented here.

## [1.1.0] - 2026-11-01

### Added

- Synthesized audio feedback with a silent fallback and `v` mute control.
- Optional voice commands, debouncing, failure shutdown, and HUD status.
- Exploded mesh view, vertex measurement, frame telemetry, and tunable config.
- Synthetic renderer benchmark, Windows launchers, and six generated demo stills.
- Demo narration and updated usage documentation.

### Changed

- Measurement mode takes precedence over two-hand transform and rotation.
- Runtime tuning follows CLI, local config, and built-in default precedence.
